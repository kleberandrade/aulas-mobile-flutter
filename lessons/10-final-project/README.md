## Objetivos

Integrar interface, dados, testes, documentação e evidências de execução em um escopo realizável.

## Atividade orientadora

Escolha um domínio, defina um fluxo pequeno e entregue uma versão reproduzível com dados sintéticos. Considere também os aplicativos do módulo 7 como alternativas.

O objetivo é uma entrega verificável. Informações de saúde ou fórmulas de produção precisam de fontes e limites de domínio; uma demonstração acadêmica não equivale a validação clínica ou química.

Use a versão atual do repositório escolhido, dados sintéticos e os passos de validação que ele documenta. Registre o ambiente e diferencie execução real, emulação e demonstração local. As atividades abaixo são propostas para o seu repositório de estudo.

## Exercícios práticos

1. **Escopo.** Objetivo: Definir uma jornada e critérios de aceitação. Conclusão: listar o fluxo principal, um erro relevante e o que fica fora da entrega.

2. **Implementação.** Objetivo: Completar a jornada com dados sintéticos. Conclusão: apresentar interface e persistência ou integração identificada de ponta a ponta.

3. **Qualidade.** Objetivo: Verificar decisões e interação críticas. Conclusão: testes relevantes aprovados e instruções para reproduzi-los.

4. **Documentação.** Objetivo: Preparar o README da entrega. Conclusão: incluir configuração, versões, licença/créditos, capturas reais e limites observados.

5. **Demonstração.** Objetivo: Reproduzir a entrega em ambiente limpo. Conclusão: executar os passos documentados e registrar resultado, pendências e retrospectiva.
