# Estudos de caso atuais

[Índice do curso](../README.pt-BR.md) · [Como estudar](study-guide.md) · [Registro da consulta](repository-snapshot.json)

Este catálogo aponta aos repositórios atuais dos estudos de caso. As modernizações recentes já estão refletidas nos manifests consultados: os aplicativos Flutter com manifesto na raiz aqui listados declaram Dart 3. Isso substitui a ideia de que todos continuam presos às versões dos artigos de 2019–2020.

A versão exata de Flutter, bibliotecas, modos locais e integrações deve seguir o README e o lockfile de cada aplicativo. Não existe uma única versão de SDK fixada para todo este índice. O registro JSON guarda o commit padrão, o requisito de Dart quando encontrado e resultados recentes de workflows; não certifica builds executados por este repositório e não deve ser interpretado como atualização automática.

## Como escolher o material

Comece pelo módulo e pelo README atual do aplicativo. Depois leia o artigo relacionado e confronte fórmulas, versões e APIs com essa implementação. Vários projetos também registram revisões das aulas do Medium em sua própria documentação; consulte as evidências no respectivo repositório.

Os fluxos Firebase, Bluetooth, câmera, IA e dados remotos podem ter modos locais, emuladores ou limitações específicas. Apresente exatamente o modo executado. Não transfira para um artigo histórico a certificação de uma build recente, nem presuma que um modo de demonstração valida um serviço real.

O [índice original](history/README-2019-2020.md) permanece como fonte dos links e do planejamento antigo. Tópicos sem URL publicada foram mantidos como histórico, não promovidos a tutoriais disponíveis.
