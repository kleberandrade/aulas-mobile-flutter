# Contributing to the course

This repository contains course guides. Application code and dependency updates belong in the individual case-study repositories.

Keep both README indexes and the ten-module sequence navigable. Modules use Portuguese and provide prerequisites, objectives, a suggested activity and actual sources. End each module with exactly five numbered exercises, each with an objective and observable completion criteria; place references and credits before the exercises.

Use current project READMEs for APIs, versions and execution instructions. Preserve the original index and article identities. Distinguish study proposals, unavailable tutorials, historical material and implemented features. Book recommendations must use verified official links and explain their connection to the course; do not reproduce paid books or their covers without permission.

Run `python3 tools/check_docs.py` from the repository root with Python 3.9 or newer. It needs no packages. Review the Markdown rendering on GitHub. The checker validates local links, anchors and course structure; it does not build external applications, check their availability or grade student work.

When updating the repository snapshot, record the lookup time and exact commits. A recent workflow result is evidence for that workflow and SHA only. Never infer a build from a documentation edit or present archived instructions as current validation.

Use synthetic classroom data, preserve attribution and licensing, and include real execution screenshots when changing a lesson's app examples. No credentials, newsletters or production account data.
